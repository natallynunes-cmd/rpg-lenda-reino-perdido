A Lenda do Reino Perdido é um jogo de RPG desenvolvido em Java, utilizando os conceitos de Programação Orientada a Objetos (POO) e banco de dados MySQL.

O jogador poderá escolher entre duas classes de heróis, enfrentar diferentes inimigos, utilizar habilidades especiais, administrar poções de cura e avançar por diferentes fases até enfrentar o grande vilão da história.

O objetivo principal será recuperar um artefato mágico responsável pela proteção do reino.
